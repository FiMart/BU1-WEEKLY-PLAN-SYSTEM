# ตั้งค่า AI — "อ่านจากรูป" (FLS-F-122) และ "ถาม AI"

> **ตอนนี้ปิดอยู่ทั้งสองปุ่ม** (27 พ.ย. 2026: มีค่าใช้จ่าย จึงปิดไว้ก่อน) · ใช้ **⚡ ถามด่วน** (ไม่ใช้ AI ฟรี) แทน
> เปิดเมื่อพร้อม: ตั้ง `ANTHROPIC_API_KEY` ใน Vercel (ด้านล่าง) แล้วใส่ใน `js/config.js`
> `aiUrl:'/api/ai-extract'` (อ่านจากรูป) และ / หรือ `aiAskUrl:'/api/ai-ask'` (ถาม AI — ปุ่มจะขึ้นในหน้าต่างถามด่วน) แล้ว deploy

- ปุ่ม **✨ อ่านจากรูปกระดาษ (AI)** ในใบ Data Flow Meter Check Sheet (FLS-F-122) ส่งรูปใบกระดาษไปที่ฟังก์ชัน `api/ai-extract.js` บน Vercel
  ฟังก์ชันนี้เรียก Claude (Anthropic) ให้อ่านค่า แล้วส่งค่ากลับมาให้คนตรวจก่อนบันทึก
- ปุ่ม **✨ ถาม AI** มุมขวาล่าง ส่งคำถามไปที่ `api/ai-ask.js` · AI ขอค้นข้อมูลผ่านเครื่องมืออ่านอย่างเดียว ซึ่งทำงานในเบราว์เซอร์ของคนถาม
  (เห็นเฉพาะข้อมูลที่บัญชีนั้นเห็นได้อยู่แล้ว) · ระดับ GA ใช้ไม่ได้ (ตรวจทั้งในแอปและในฟังก์ชัน)
- ทั้งสองใช้ key เดียวกัน (`ANTHROPIC_API_KEY`) และรุ่นเดียวกัน (`AI_MODEL`)

## สิ่งที่ทีมต้องทำ (ครั้งเดียว)

1. สร้าง API key ที่ https://console.anthropic.com → API Keys (ใช้บัญชีของบริษัท และตั้งวงเงินใช้งานต่อเดือนไว้)
2. ใน Vercel → โปรเจกต์ของเว็บนี้ → Settings → Environment Variables เพิ่ม
   - `ANTHROPIC_API_KEY` = key ที่สร้าง (เลือก Production; ถ้าใช้ Preview ด้วยก็ติ๊ก Preview)
3. Deploy ใหม่ (Vercel ติดตั้ง `@anthropic-ai/sdk` จาก `package.json` ให้เอง)

**ห้าม** ใส่ key ไว้ใน `js/config.js` หรือไฟล์ใดใน `js/` — key อยู่บนเซิร์ฟเวอร์เท่านั้น

## ค่าที่ตั้งเพิ่มได้ (ไม่บังคับ)

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `AI_MODEL` | `claude-sonnet-5-5` | เปลี่ยนรุ่นโมเดล (ดูตารางด้านล่าง) |
| `AI_EFFORT` | `medium` | อ่านจากรูป: `low` / `medium` / `high` — ยิ่งสูงยิ่งคิดนาน อ่านลายมือยากได้ดีขึ้น แต่ช้าและแพงขึ้น |
| `AI_ASK_EFFORT` | `medium` | ถาม AI: `low` (เร็ว ถูก) / `medium` / `high` (ค้นละเอียดขึ้น) |
| `SUPABASE_URL` / `SUPABASE_ANON_KEY` | ค่าเดียวกับ `js/config.js` | ใช้ตรวจว่าคนกดเข้าสู่ระบบและมีสิทธิ์แผนก BU1 |

| `claude-haiku-5-5` | $0.10 / $0.50 | ถูกและเร็วที่สุด แต่อาจอ่านลายมือไทย / ตัวเลขเล็ก ๆ ผิดมากกว่า (ไม่มีระบบลองใหม่อัตโนมัติเมื่อ AI ปฏิเสธ) |

เปลี่ยนค่าใน Vercel แล้วต้อง **Redeploy** ค่าใหม่ถึงจะมีผล · กล่องผลในแอปบอกว่าใบนั้น "อ่านโดย" รุ่นไหน ใช้เทียบได้
วิธีเลือก: ลองอ่านใบจริงชุดเดียวกัน 5–10 ใบกับแต่ละรุ่น นับจำนวนค่าที่ต้องแก้ แล้วเลือกรุ่นที่ถูกที่สุดที่ยังแม่นพอ

ปิดปุ่มอ่านจากรูปได้โดยใส่ `aiUrl:''` และปิดถาม AI ด้วย `aiAskUrl:''` ใน `BU1_CONFIG` (`js/config.js`)

### ค่าใช้จ่ายของ "ถาม AI"

หนึ่งคำถามอาจเรียก AI 2–4 รอบ (ค้นข้อมูลแล้วสรุป) และส่งข้อมูลแผนที่ค้นเจอไปด้วย จึงแพงกว่าการอ่านรูปหนึ่งครั้ง
ระบบใช้ prompt caching ให้ส่วนที่ซ้ำ (คำสั่ง + เครื่องมือ + แชตก่อนหน้า) คิดราคาถูกลงในรอบถัดไป · แชตหนึ่งถามได้ไม่เกิน 20 คำถาม แล้วต้องกด "แชตใหม่"
ควรตั้งวงเงินต่อเดือนใน console.anthropic.com และดูยอดใช้จริงในสัปดาห์แรก

## ความปลอดภัย / ข้อมูล

- เรียกได้เฉพาะคนที่เข้าสู่ระบบด้วยบัญชีกลาง **และ** มีแถวใน `public.user_roles` ของแผนก BU1 (ตรวจด้วย token ของคนนั้นเอง)
- รูปถูกส่งไป Anthropic เฉพาะตอนกดปุ่ม ไม่มีการเก็บรูปหรือคำตอบไว้ที่ไหน
- ถาม AI: คำถาม และข้อมูลที่ AI ค้นเพื่อตอบ (เช่น แผน ลูกค้า ชื่อทีม ผู้ติดต่อ) ถูกส่งไป Anthropic · แชตเก็บใน localStorage ของเบราว์เซอร์นั้นเท่านั้น ไม่เขียนลงฐานข้อมูล · AI แก้ข้อมูลไม่ได้ (ไม่มีเครื่องมือเขียน)
- ค่าที่อ่านได้เข้าไปในใบเมื่อคนติ๊กเลือกและกด "ใส่ค่าที่เลือกลงในใบ" และบันทึกจริงเมื่อกด "บันทึก" เท่านั้น
- ค่าใช้จ่ายคิดตามการใช้งานในบัญชี Anthropic (ประมาณ 1 ครั้งต่อการกดอ่าน 1 ครั้ง)
