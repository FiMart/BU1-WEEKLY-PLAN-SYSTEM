# คู่มือเข้าสู่ระบบและสมัครสมาชิก · BU1 Weekly Plan

คู่มือนี้สำหรับทีม BU1 Lab อธิบายวิธีเข้าสู่ระบบ สมัครสมาชิก ลืมรหัสผ่าน และสิ่งที่ต้องทำเมื่อระบบแจ้งว่ายังไม่มีสิทธิ์

## สรุปสั้น

| สถานะของคุณ | ต้องทำอะไร |
| --- | --- |
| มีบัญชีบริษัทอยู่แล้ว | เข้าสู่ระบบด้วยอีเมลและรหัสผ่านเดิมได้เลย ไม่ต้องสมัครใหม่ |
| ยังไม่มีบัญชี | สมัครสมาชิก → กดยืนยันในอีเมล → รอผู้ดูแลระบบเพิ่มสิทธิ์แผนก BU1 |
| ลืมรหัสผ่าน | กด "ลืมรหัสผ่าน?" ที่หน้าเข้าสู่ระบบ แล้วตั้งรหัสใหม่จากลิงก์ในอีเมล |



---

## 1. เข้าสู่ระบบ

1. เปิดเว็บ BU1 Weekly Plan ระบบจะแสดง "กำลังเชื่อมต่อ…" สักครู่ แล้วขึ้นหน้า **เข้าสู่ระบบ**
2. ใส่ **อีเมล** และ **รหัสผ่าน** ของบัญชีบริษัท
   - กด **แสดง** ท้ายช่องรหัสผ่านเพื่อตรวจว่าพิมพ์ถูก (กดอีกครั้งเพื่อซ่อน)
3. กด **เข้าสู่ระบบ**
4. ถ้ามีสิทธิ์แผนก BU1 แล้ว จะเข้าหน้าแผนงานทันที

**จำการเข้าสู่ระบบ:** เครื่องนี้จะจำการเข้าสู่ระบบไว้จนกว่าจะกด **ออกจากระบบ** ถ้าใช้เครื่องส่วนกลางหรือเครื่องของคนอื่น ให้ออกจากระบบทุกครั้งเมื่อใช้เสร็จ

## 2. สมัครสมาชิก

1. ที่หน้าเข้าสู่ระบบ กดแท็บ สมัครสมาชิก (หรือลิงก์ "ยังไม่มีบัญชี? สมัครสมาชิก")
2. กรอกข้อมูล

   | ช่อง | บังคับ | หมายเหตุ |
   | --- | --- | --- |
   | ชื่อ-นามสกุล | ✔ | เช่น สมชาย ใจดี · ใช้แสดงชื่อในระบบ |
   | รหัสพนักงาน | — | ใส่ถ้ามี เช่น F0123 |
   | อีเมลบริษัท | ✔ | ใช้เป็นชื่อผู้ใช้ตอนเข้าสู่ระบบ |
   | รหัสผ่าน | ✔ | อย่างน้อย 8 ตัวอักษร แถบใต้ช่องบอกความแข็งแรง (อ่อน · พอใช้ · ดี · แข็งแรง) แนะนำให้ผสมตัวอักษร ตัวเลข และสัญลักษณ์ |
   | ยืนยันรหัสผ่าน | ✔ | พิมพ์ให้ตรงกับช่องรหัสผ่าน |

3. ติ๊ก **ยืนยันว่าเป็นพนักงาน BU1 Lab และจะใช้บัญชีนี้เพื่องานของแผนกเท่านั้น** ถ้าไม่ติ๊ก ระบบจะไม่ให้สมัครสมาชิก
4. กด **สมัครสมาชิก**
5. ระบบแสดงหน้า **สมัครสมาชิกแล้ว** พร้อมขั้นตอนที่เหลือ

### หลังสมัคร: ยืนยันอีเมล และรอสิทธิ์

| ขั้น | สิ่งที่ต้องทำ |
| --- | --- |
| ✅ สร้างบัญชีแล้ว | ระบบสร้างบัญชีกลางให้แล้ว |
| ② รอสิทธิ์แผนก BU1 | แจ้งผู้ดูแลระบบให้เพิ่มสิทธิ์แผนก BU1 ให้อีเมลนี้ (ดูข้อ 6) |

> **ระบบกลางอาจปิดการสมัครเอง:** ถ้ากดสมัครแล้วขึ้นว่า "ระบบกลางปิดการสมัครเอง" แปลว่าผู้ดูแลระบบกลางเป็นคนสร้างบัญชีให้เท่านั้น ให้ติดต่อผู้ดูแลระบบเพื่อขอบัญชี

## 3. ขึ้นหน้า "ยังไม่มีสิทธิ์เข้าถึงข้อมูลแผนกนี้"

แปลว่าเข้าสู่ระบบสำเร็จแล้ว แต่บัญชีนี้ยังไม่ได้รับสิทธิ์แผนก BU1

1. แจ้ง Admin ให้เพิ่มสิทธิ์แผนก BU1 ให้อีเมลที่แสดงบนหน้านั้น
2. เมื่อได้รับแจ้งว่าเพิ่มแล้ว กด **ตรวจสอบอีกครั้ง** ไม่ต้องออกจากระบบ
3. ถ้าเข้าสู่ระบบผิดบัญชี กด **ออกจากระบบ** แล้วเข้าสู่ระบบด้วยบัญชีที่ถูกต้อง

## 4. ลืมรหัสผ่าน

1. ที่หน้าเข้าสู่ระบบ กด **ลืมรหัสผ่าน?**
2. ใส่อีเมลที่ใช้สมัคร แล้วกด **ส่งลิงก์ตั้งรหัสผ่านใหม่**
3. เปิดอีเมล แล้วกดลิงก์ในอีเมล (ถ้าไม่เจอ ดูในโฟลเดอร์ Spam)
4. ลิงก์จะพากลับมาที่หน้า **ตั้งรหัสผ่านใหม่** ใส่รหัสใหม่ (อย่างน้อย 8 ตัวอักษร) สองครั้งให้ตรงกัน
5. กด **บันทึกรหัสผ่านใหม่** ระบบจะเข้าสู่ระบบให้ทันที

รหัสผ่านใหม่ใช้กับทุกระบบที่ใช้บัญชีกลาง

## 5. ระดับสิทธิ์ในระบบ

หลังเข้าสู่ระบบ ดูระดับสิทธิ์ของตัวเองได้ที่การ์ดชื่อมุมล่างซ้าย (บนมือถือ: รูปโปรไฟล์มุมขวาบน) → **บัญชีของฉัน**

| ระดับ | ทำอะไรได้ |
| --- | --- |
| ผู้ดูแลระบบ (Admin) | ทำได้ทุกอย่าง: แผนงาน ข้อมูลหลัก ลบแผน นำเข้าข้อมูล และจัดการผู้ใช้ของแผนก |
| ผู้วางแผน (Planer) | เพิ่ม แก้ และลบแผนงานของทุกคน แก้ข้อมูลหลัก และนำเข้าข้อมูล · จัดการผู้ใช้ไม่ได้ |
| วิศวกร (Engineer) | เพิ่มและแก้แผนงาน เปลี่ยนสถานะ แนบรูปและไฟล์ · แก้ข้อมูลหลักและลบแผนไม่ได้ |
| ฝ่ายขาย (Sale) | เพิ่มและแก้แผนงาน เปลี่ยนสถานะ ค้นหา และดาวน์โหลดรายงาน · แก้ข้อมูลหลักและลบแผนไม่ได้ |
| GA | ดูแผนงาน และระบุรถ / ทะเบียนให้แผนงานที่ขอรถส่วนกลาง |
| ดูอย่างเดียว (Viewer) | เปิดดูแผนงานได้ แก้ไขไม่ได้ · ไม่เห็นเมนู Safety Training |

บัญชีที่มีสิทธิ์แผนกแล้วแต่ยังไม่ได้กำหนดระดับ จะเป็น **ดูอย่างเดียว** จนกว่าผู้ดูแลระบบจะเปลี่ยนให้ ถ้าต้องการสิทธิ์เพิ่ม ให้ติดต่อผู้ดูแลระบบของแผนก

## 6. สำหรับผู้ดูแลระบบ: ให้สิทธิ์คนใหม่

1. ให้คนนั้นสมัครสมาชิกและยืนยันอีเมลให้เรียบร้อย (หรือผู้ดูแลระบบกลางสร้างบัญชีให้)
2. เข้าสู่ระบบด้วยบัญชีระดับ **ผู้ดูแลระบบ** → **จัดการข้อมูล** → **ผู้ใช้งานระบบ**
3. ใส่ **อีเมลของบัญชีกลาง**, ชื่อ (ไม่บังคับ) และเลือก **ระดับสิทธิ์** แล้วกด **ให้สิทธิ์แผนก BU1**
4. เปลี่ยนระดับของคนที่มีอยู่แล้ว: เลือกระดับใหม่ในตาราง ระบบบันทึกทันที
5. เอาสิทธิ์ออก: กด **เอาสิทธิ์ออก** แล้วกดอีกครั้งเพื่อยืนยัน (บัญชียังอยู่ แค่เข้าข้อมูล BU1 ไม่ได้)

ผู้ดูแลระบบเปลี่ยนระดับหรือเอาสิทธิ์ของตัวเองออกไม่ได้ ถ้าเพิ่มสิทธิ์ในแอปแล้วคนนั้นยังขึ้นหน้า "ยังไม่มีสิทธิ์เข้าถึงข้อมูลแผนกนี้" ให้ติดต่อผู้ดูแลระบบกลาง

## 7. ออกจากระบบ

- **คอมพิวเตอร์:** กด **ออกจากระบบ** ใต้การ์ดชื่อมุมล่างซ้าย
- **ทุกอุปกรณ์:** เปิด **บัญชีของฉัน** แล้วกด **ออกจากระบบ**

ระบบจะถามยืนยันก่อน ครั้งหน้าต้องเข้าสู่ระบบด้วยอีเมลและรหัสผ่านอีกครั้ง

## 8. ข้อความแจ้งเตือนที่พบบ่อย

| ข้อความ | สาเหตุ / วิธีแก้ |
| --- | --- |
| อีเมลหรือรหัสผ่านไม่ถูกต้อง | ตรวจตัวสะกดอีเมล และกด "แสดง" เพื่อดูรหัสผ่าน · ถ้าจำไม่ได้ ใช้ "ลืมรหัสผ่าน?" |
| บัญชีนี้ยังไม่ได้ยืนยันอีเมล | เปิดลิงก์ยืนยันในอีเมล (ดู Spam ด้วย) แล้วเข้าสู่ระบบอีกครั้ง |
| อีเมลนี้มีบัญชีแล้ว | ไม่ต้องสมัครใหม่ เข้าสู่ระบบด้วยรหัสผ่านเดิม หรือกด "ลืมรหัสผ่าน?" |
| ระบบกลางปิดการสมัครเอง | ติดต่อผู้ดูแลระบบกลางเพื่อขอบัญชี |
| รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร | ตั้งรหัสให้ยาวขึ้น |
| รหัสผ่านทั้งสองช่องไม่ตรงกัน | พิมพ์ช่อง "ยืนยันรหัสผ่าน" ใหม่ให้ตรงกัน |
| ติ๊กยืนยันว่าเป็นพนักงาน BU1 Lab ก่อนสมัคร | ติ๊กช่องยืนยันท้ายฟอร์ม |
| รูปแบบอีเมลไม่ถูกต้อง | ตรวจว่ามี @ และโดเมน เช่น `name@company.co.th` |
| ลองหลายครั้งเกินไป รอสักครู่แล้วลองใหม่ | ระบบจำกัดจำนวนครั้ง รอสักครู่แล้วลองใหม่ (กดส่งอีเมลยืนยัน / ลืมรหัสผ่านซ้ำบ่อย ๆ ก็ติดข้อจำกัดนี้) |
| เชื่อมต่อ Supabase ไม่ได้ / เชื่อมต่อระบบเข้าสู่ระบบไม่สำเร็จ | ตรวจอินเทอร์เน็ต แล้วโหลดหน้าใหม่ · ถ้ายังไม่ได้ แจ้งผู้ดูแลระบบ |
| ยังไม่มีสิทธิ์แผนก BU1 ติดต่อผู้ดูแลระบบกลาง | ดูข้อ 3 |
